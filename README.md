# Deposit Dispute Compass

Build a responsive web app called RentResolve, an AI-assisted tenancy deposit dispute navigator for university students and other private renters in England.

TIME AND SCOPE: This is a three-day student project. Prioritise a working, polished prototype over complex infrastructure.

DESIGN:

Modern, approachable legal technology design. Use images of real houses in the UK. 

Warm off-white background, dark navy typography, muted teal accents.

Accessible typography, generous spacing, rounded cards, simple icons.

Desktop dashboard and mobile-friendly layout.

Avoid excessive animations, generic stock imagery and intimidating legal language.

PAGES:

Landing page: "Your tenancy dispute, made clearer."

Guided intake: ask about the deposit dispute and the documents available.

Case dashboard: summary, amount disputed, timeline and next steps.

Evidence review: documents, supported facts and missing information.

Resolution options: explain the relevant deposit dispute process with official source links.

Draft letter: an editable email that can be copied.

FUNCTIONAL REQUIREMENTS:

Use React and TypeScript if supported by the platform.

Use local sample data initially. No authentication or paid services.

Every main navigation link and button must work.

Include a "Try a sample case" button that opens a complete fictional case.

Include a "Start my own case" flow.

Display loading, empty and error states where appropriate.

Make all generated information editable before use.

Do not pretend sample data was generated by a live AI model.

Add a clear disclaimer that the app provides general information, not a determination of legal rights or a substitute for professional advice.

Use the fictional sample scenario of a student disputing a £1,200 carpet replacement deduction from an £1,800 deposit.

Generate the complete application with functional navigation and consistent sample data. Do not add accounts, payment features, or a complicated backend.
